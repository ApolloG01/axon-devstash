## Neon MCP Rules

**CRITICAL**: When using the Neon MCP for any database operation:

- Always use the **axon-devstash** Neon project.
- Always use the **development** branch within that project.
- **Never** read from or write to the production branch unless the user explicitly says "use production" or "production branch" in their message.
- If you are unsure which project or branch to use, ask before proceeding.
